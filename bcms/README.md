# Baidyanath College of Medical Science - Frontend

Premium frontend-only college website built with Next.js, TypeScript and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current phase

- Frontend only
- 25 main pages + reusable detail routes
- Local TypeScript data/mock services
- No Supabase, Firebase, database, authentication, admin panel or CRUD API
- Structured so a backend can be connected later without redesigning the UI
